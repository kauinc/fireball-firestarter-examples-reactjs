# fireball-firestarter-examples-clients

FireStarter **client** examples, grouped by language, then by game.

```
ReactJS/
  DoofTroop/     # React + LiveKit + Supabase HUD (Doof Troop)
Unity/
  …              # future Unity client examples
```

## Quick start (Doof Troop / React)

```bash
cd ReactJS/DoofTroop
cp .env.example .env   # optional overrides
npm install
npm run dev
```

See [ReactJS/DoofTroop/README.md](ReactJS/DoofTroop/README.md) for env vars, layout, and overlays.
